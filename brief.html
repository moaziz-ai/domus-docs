What This Is

Domus (and all Exceed companies - NG, Phoenix, Nomos, Telos) currently use an Excel spreadsheet (V3) to build project cost estimates. The goal is to digitize this into a proper web application that replaces the Excel workflow entirely.

This is an internal operations tool - not customer-facing. The people using it daily are quantity surveyors (like Anthony at Domus) and project managers across the Exceed group.

How the Excel Works (Plain English)

The Excel has 3 sheets. Here is exactly what each one does.

Sheet 1: Project Markup Calculator

This is the pricing brain. It has three tables on one sheet.

Table A - Trade Markup Rates (17 categories)

Every line item in an estimate belongs to one trade. Each trade has a fixed markup %:

TradeMarkup
Base Works40%
Furniture40%
HVAC35%
MEP35%
Marble35%
Joinery35%
Waterproofing35%
Light Carpentry30%
Steel Works30%
Aluminium Works30%
Glass30%
Painting25%
Civil Works25%
Masonry25%
Subcontracted15%
Preliminary10%
Demolition10%

Table B - Value Discount Tiers

The bigger the project, the more discount on the markup. This discount reduces the markup %, NOT the base cost.

Total Project Cost (AED)Discount on Markup
10,000+5%
25,000+10%
50,000+20%
100,000+30%
500,000+40%
1,000,000+50%
2,500,000+60%
Example A 100,000 AED project gets 30% off the markup. So a Joinery item (35% markup) would effectively have: 35% x (1 - 30%) = 24.5% markup.

Table C - Project Summary (auto-calculated)

  • Domus Cost = total cost of all non-subcontracted line items (pulled from Sheet 2)
  • Subcontractor Cost = total cost of all subcontracted line items (pulled from Sheet 2)
  • Total Project Cost = Domus Cost + Subcontractor Cost
  • Markup Discount = looked up from the Value Discount table based on Total Project Cost
  • Final Markup % = (Total Quoted Price / Total Cost) - 1 (this is a result, not an input)
  • Total Project Price (Before VAT) = Total Project Cost x (1 + Final Markup %)

There is also an optional manual discount row that can be applied on top.

Sheet 2: Project Estimation (the main BOQ)

This is where the actual estimate gets built. It is the biggest sheet.

Header (rows 2-8)

Project info: supervisor, project name, location, client, email, quote number, date.

Line Items (rows 13-25)

Each row is one line item in the estimate. Each line item has:

  • SL. NO. - item number (1, 1.1, 1.2, etc.)
  • DESCRIPTION - what the work is
  • UNIT - unit of measurement (M2, Item, etc.)
  • QTY - quantity
  • TYPE - which trade category (dropdown from the 17 trades)
  • MARKUP - auto-filled via VLOOKUP from Sheet 1 based on trade type

Sub-items (up to 3 per line item)

Each line item can have up to 3 sub-items. Each sub-item breaks down into:

  • Material: Rate x Quantity
  • Labour: Rate x Employees x Hours x Days
  • Total = Material + Labour
  • Unit Total = Total x QTY (from the main line item)
Sub-item Total = (Material Rate x Material Qty) + (Labour Rate x Employees x Hours x Days)

Grand Total for a line item = Sub-item 1 Total + Sub-item 2 Total + Sub-item 3 Total

The RATE and client-facing TOTAL columns

This is the key pricing formula:

RATE = Grand Total Cost x (1 + (Trade Markup x (1 - Value Discount) - Manual Discount))
TOTAL = QTY x RATE

The rate the client sees = the internal cost, marked up by the trade's percentage, reduced by the value discount tier, minus any manual discount.

Summary Rows

  • Total Domus Cost = sum of all unit totals EXCEPT subcontracted items
  • Total Subcontracted Cost = sum of unit totals WHERE type = "Subcontracted"
  • Total Cost = sum of ALL unit totals
  • Total (client-facing) = sum of marked-up prices
  • 5% VAT = Total x 0.05
  • Total Inclusive of VAT = Total + VAT

Sheet 3: Item Schedule

A simpler version used for detailed material/labour breakdowns on specific items (like a door or a fixture). Same cost structure but without the markup layer.

Line items each have:

  • Description
  • Material: Rate x Unit x Quantity
  • Labour: Rate x Employees x Hours x Days
  • Total = (Material Rate x Qty) + (Labour Rate x Employees x Hours x Days)

At the bottom:

  • Total Domus Cost = Total - Subcontracted items
  • Total Subcontracted Cost = items marked as "Subcontracted"
  • Grand Total = sum of all items

How It All Connects

1
User fills in line items on Sheet 2 (description, qty, trade type, sub-item costs)
2
Each line item's trade type auto-looks-up the markup % from Sheet 1
3
Sub-item costs (material + labour) are totalled per line item
4
The client-facing RATE applies: cost + markup - value discount - manual discount
5
Sheet 1 auto-calculates the total project cost and determines the value discount tier
6
The value discount feeds back into every line item's rate calculation (circular dependency resolved by Excel's iterative calculation)
7
Final output: client sees RATE and TOTAL columns. Internal team sees full cost breakdown.
Circular Reference The value discount is determined by the TOTAL project cost, which itself depends on the markup, which depends on the discount. This creates a circular reference that Excel resolves iteratively. The web app needs to handle this too (loop until stable or solve algebraically).

V2 Features

  • All 17 trade categories with correct markup rates
  • Value discount tiers applied to markup
  • Weighted average markup calculation
  • Sub-item breakdown (material + labor)
  • Multi-company support
  • Summary dashboard
  • Templates library
  • Estimate versioning with history
  • Role-based access (Admin / Estimator / Viewer)
  • Excel export via SheetJS
  • Analytics dashboard
  • Undo/redo
Known Issues (from Muhasin's feedback, April 9) Some individual line items do not add up properly to the total when additional items are included. Overall figures appear correct, but per-line-item math needs a pass. Calculation logic needs to be QA'd against real Excel scenarios.
